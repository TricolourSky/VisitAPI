Put dialogue background images and videos here.

Reference one from a .dlg node header, e.g.:

    <root> bg: ragman.png
    ...

Plain file names are looked up in this backgrounds/ folder.
  Images: png / jpg / jpeg / bmp
  Videos: mp4 / webm / mov / avi / mkv / ogv  (auto-loop, H.264 mp4 recommended)

A trader's initial tab background can be set with:
    config/VisitAPI/<traderId>.png

The Ragman example uses no backgrounds, so this folder can stay empty.
